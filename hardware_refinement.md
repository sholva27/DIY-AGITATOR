# Raffinement Hardware : Vers une Version Professionnelle

## 1. Sécurité et E-STOP
Le Kill Switch (GPIO 5) est une mesure de sécurité "Defense-in-depth". Il est particulièrement recommandé si un système de chauffage est ajouté au mélangeur.

## 2. Choix du Ventilateur
Pour maximiser le couple de couplage magnétique, privilégiez un ventilateur à **forte pression statique** (souvent utilisés dans les serveurs) plutôt que de vous fier uniquement au type de roulement.
